# Pathology — Session 2: Cell Injury, Necrosis and Repair

`pathology-session2-bilingual.pdf` (60 pp) — bilingual English / Persian.

Covers intracellular accumulations and calcification, necrosis and apoptosis,
and regeneration and repair.

Compiled from Zhejiang University School of Medicine lecture slides
(Chapters 1–2, Prof. Mao Zhengrong) with Robbins &amp; Kumar *Basic Pathology*
11e and Pathoma.

## Note on this folder

This guide predates the `src/` generator used by every other folder in the
repository, so there is **no build system here** — only the finished PDF, and
there is no separate English-only edition. If it is ever rebuilt, it should be
rebuilt on the same `<fa>` single-source convention as the others; see
`../lab-1-introduction/README.md` for how that works.

The file was previously called `Pathology_Session2_BILINGUAL_Expanded_Edition.pdf`
and was renamed for consistency with the rest of the repository.
