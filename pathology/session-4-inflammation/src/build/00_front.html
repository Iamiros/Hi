How to use this guide

Part 1 of the inflammation lecture stays entirely inside the blood vessel: how it dilates, leaks, and recruits leukocytes, and which molecules run each step. Morphologic subtypes (serous, fibrinous, suppurative, granulomatous inflammation), systemic manifestations (fever, leukocytosis), and the clinical vocabulary (abscess, sinus, fistula, bacteremia) belong to Part 2 of the lecture, not yet covered here.

Reading the margin rail

A thin rule in the outer margin marks a sidenote: a definition, a unit, or an eponym tied to the paragraph beside it. A CLINICAL box is a bedside correlate; an EXAM TRAP box is a distinction examiners like to test; a MNEMONIC box is a memory aid. Every cascade is drawn as a numbered mechanism chain or a purpose-built diagram, never a photograph standing in for a process it cannot show.

Method

Text extracted from the 95-slide deck and the 22-point learning-objectives outline, restructured around the causal order the lecturer teaches (vascular change first, then leukocyte recruitment, then the molecules behind both), and checked twice against Robbins Basic Pathology 11e for accuracy, completeness, and the current name of every mediator. Two real H&E micrographs are carried over from the lecture slides (credited in src/img/CREDITS.md); every mechanism diagram is an original SVG built for this guide.
