How to use this guide

Every specimen card follows the same order the bench expects: organ, gross or microscopic description, then diagnosis. Read the description before the diagnosis and try to name the lesion yourself; the diagnosis line is there to check your answer, not to replace the exercise.

Reading the tags

Gross marks a naked-eye specimen observation; Micro marks a microscopic one. A LAB TECHNIQUE box explains how to describe what you see; an EXAM TRAP box flags a distinction spot exams like to test.

Method

Specimen list, gross photographs, and slide micrographs extracted directly from the lab's own deck (a screenshot-based specimen viewer; interface chrome cropped out, credited image by image in src/img/CREDITS.md). Content checked twice against Robbins Basic Pathology 11e for the correct name, mechanism, and Latin/English terminology of every pattern.
